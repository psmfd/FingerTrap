Twelve scenarios match the maintained release

Both repetitions pass for each binary, and all twelve final normalized transcripts match between the released maintained baseline and candidate. Managed-policy changes introduce no drift in these ordinary CLI scenarios. The separate isolation matrices exercise managed mode.
